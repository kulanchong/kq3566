# KQ3566 ImmortalWrt Adaptation

KQ3566 is an RK3566 DDR3 board derived from the NanoPi R3S style layout.
It uses four NT5CC256M16ER-EK DDR3 chips, an internal RTL8211F-CG RGMII
PHY, and a PCIe RTL8111H-CG Ethernet controller.

## Board Support

The adaptation adds:

- Linux DTS: `rk3566-kq3566.dts`
- U-Boot target: `kq3566-rk3566`
- Rockchip DDR loader: `rk3566_ddr_1056MHz_v1.25.bin`
- OpenWrt target device: `kq_kq3566`
- Runtime Ethernet layout: LAN `eth1`, WAN `eth0`
- Early preinit/failsafe interface: `eth0`
- SARADC recovery key support on SARADC channel 0
- WORKING/status LED on `GPIO0_C3`
- HDMI connector routing and Rockchip DRM/display-connector package support
- eMMC raw image output in addition to the standard sysupgrade image

## Build

Use menuconfig:

```sh
make menuconfig
```

Select:

```text
Target System: Rockchip
Subtarget: ARMv8 boards
Target Profile: KQ KQ3566
```

Build:

```sh
make -j$(nproc) V=s
```

The images are written to:

```text
bin/targets/rockchip/armv8/
```

Expected KQ3566 image files:

```text
immortalwrt-rockchip-armv8-kq_kq3566-ext4-sysupgrade.img.gz
immortalwrt-rockchip-armv8-kq_kq3566-squashfs-sysupgrade.img.gz
immortalwrt-rockchip-armv8-kq_kq3566-ext4-emmc.img.gz
immortalwrt-rockchip-armv8-kq_kq3566-squashfs-emmc.img.gz
```

Use the `sysupgrade.img.gz` images for TF/SD card writing and normal
OpenWrt sysupgrade. Use the `emmc.img.gz` images for eMMC flashing;
decompress them first if the flashing tool needs a raw full-disk image.

## Notes

- U-Boot console baud rate is `1500000`.
- The DDR loader is RK3566 DDR3 v1.25.
- The board has discrete regulators, not the R3S RK809/TCS4525/HYM8563
  power tree.
- The HDMI software route is enabled in DTS. If DRM shows an active HDMI
  connector and valid EDID but no image, check HDMI 0.9V/1.8V analog rails,
  `HDMI_TX_REXT`, ESD parts, connector soldering, and TMDS pair routing.
- `fw_env.config` is optional on this board because U-Boot may report
  `Loading Environment from nowhere`; firstboot now skips U-Boot default
  import when `/etc/fw_env.config` is absent.
